# Stride Fitness: Week 1

 Fitness Studio website
Week 1; Build a landing page with HTML and an external CSS file.


## Project overview

Stride Fitness is a fictional gym that offers strength, cardio, and mobility classes for every level. This week's deliverable is the landing page. Its job is to explain what Stride offers and get visitors to sign up for a free week.

## Files

```
fitness-site/
├── index.html   # Page structure and content
├── styles.css   # All styling (external stylesheet)
└── README.md    # Project documentation
```

## Page sections

1. **Header:** logo and navigation links that jump to each section
2. **Hero:** headline, short description, and the main call to action
3. **Programs:** three program cards (Strength, Cardio, Mobility)
4. **How it works:** three numbered steps
5. **Sign up:** email form for the free week
6. **Footer:** copyright line

## What I used

- Semantic HTML5 elements (`header`, `nav`, `main`, `section`, `article`, `footer`)
- One external stylesheet linked in the `<head>`
- CSS custom properties (variables) for colors and fonts
- Flexbox for the header and form, CSS Grid for the program cards and steps
- A responsive layout with a media query for small screens
- Google Fonts: Barlow Condensed and Barlow
- Accessibility basics: labeled form input, visible keyboard focus, `lang` attribute, and reduced-motion support

## How to run it

1. Download or clone this folder.
2. Open `index.html` in any web browser.

No build tools or installs are needed.

## Design choices

- **Colors:** navy and cool white for a clean base, with orange reserved for buttons so the call to action stands out.
- **Type:** a condensed heading font for an athletic feel, paired with a plain, readable body font.
- **Layout:** left-aligned text and short line lengths for easy reading.
